# MA-546: Introduction to Quantitative Finance — Assignments

Solutions to the four assignments of **MA-546 (Introduction to Quantitative Finance)** at IIT Mandi. The work is data-driven analysis of Indian markets in Python (pandas, yfinance, matplotlib), with written reports.

| Assignment | Topics |
|---|---|
| [Assignment-1](Assignment-1) | The NIFTY 50's top-10 constituents by weight over 10 years (index concentration and sector leadership), a 10-year Gold vs Crude Oil correlation study, and year-wise sector market-cap and trading-activity analysis |
| [Assignment-2](Assignment-2) | Stock selection (HDFC, Infosys, Maruti, Sun Pharma), a 10-year/5-year train–test split, support, resistance and trend identification, chart patterns (double top/bottom, head & shoulders), and a rule-based trading strategy with backtesting and metrics |
| [Assignment-3](Assignment-3) | Written solutions |
| [Assignment-4](Assignment-4) | Written solutions |

Each folder contains the question paper, the code, the outputs and a report. Assignment-2 has its own README explaining its folders. `All-Zips/` holds the archives as submitted.

```bash
pip install pandas numpy matplotlib yfinance
python Assignment-1/Q1.py
```
